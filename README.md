# 🌿 AI-Powered Plant Disease Diagnostic & Care System

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://plantdiseaseapp-fefljywul2tbsmgjqzeua2.streamlit.app/)

An end-to-end Deep Learning Web Application built with **Streamlit** and **EfficientNetB0** (TensorFlow) to diagnose crop leaf diseases and provide instant treatment recommendations using Google's **Gemini AI**.

---

## 🔗 Live Demo
👉 **[Click Here to Access the Live Web App](https://plantdiseaseapp-fefljywul2tbsmgjqzeua2.streamlit.app/)**

---

## 🚀 Features
- **High-Accuracy Disease Detection:** Uses Transfer Learning (EfficientNetB0) trained on the PlantVillage dataset.
- **Smart AI Advisory:** Integrated with Gemini API to suggest organic solutions, chemical remedies, and preventive measures.
- **Interactive Web UI:** Simple and clean user interface built using Streamlit.

## 🛠️ Tech Stack
- **Framework:** Python, Streamlit
- **Machine Learning:** TensorFlow, Keras (EfficientNetB0)
- **Generative AI:** Google Gemini API
- **Dataset:** PlantVillage Dataset
